## robots.txt Configuration

**Production (`NODE_ENV=production`):**
```
User-agent: *
Allow: /
Disallow: /api/
Disallow: /_next/

Sitemap: https://www.yedii.com/sitemap.xml
Host: https://www.yedii.com
```

**Non-production (development/staging):**
```
User-agent: *
Disallow: /
```

> [!IMPORTANT]
> The robots.txt is environment-gated. Staging/preview deployments are automatically blocked from crawling. Ensure `NODE_ENV=production` is set correctly on the production host.
